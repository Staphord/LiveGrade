{% comment %} Saves without a visible reload for a setup step that lives on its own page. Wrap the step body in an element with data-inline-region. Every POST form in it submits in the background; the response replaces the region and the stepper, and the flash messages show as toasts. Links marked data-inline-nav load the same way (edit and cancel). Open details keep their state when they have an id, unless marked data-server-open. Textareas marked data-autogrow start on one line, grow as the text grows and stop at data-word-limit words. Anything the script cannot handle falls back to a normal page load. {% endcomment %}
